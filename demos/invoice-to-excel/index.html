InvoiceToExcel

An offline Windows/local CLI utility that scans a folder of text-based PDF invoices and writes a reviewable XLSX table.

Good for

Small businesses that receive invoices as PDFs and manually copy fields into spreadsheets.

Privacy-friendly

No network, no cloud services, no paid APIs, and no credentials in the MVP flow.

Reviewable output

Rows are not silently dropped. Files needing manual review are marked instead.

Current scope

Text-based PDFs and simple extractable invoice text. No OCR in the current MVP.

Command

python invoice_to_excel.py INPUT_FOLDER OUTPUT.xlsx

Test status

Local test suite: 5 tests passed.

Client version can add

  • Client-specific invoice formats and fields.
  • OCR for scanned invoices if approved.
  • Export rules for accounting workflows.
  • Scheduled folder processing.
