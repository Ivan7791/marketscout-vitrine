# Где разместить первую презентацию MarketScout

## Мой выбор для старта

Сначала делаем статический лендинг. Публикация — GitHub Pages или Cloudflare Pages. До публикации смотрим локально и правим текст.

## Варианты

1. GitHub Pages
   - Цена: бесплатно для публичного репозитория.
   - Плюс: просто, надёжно, можно подключить домен позже.
   - Минус: нужен GitHub и аккуратная настройка репозитория.
   - Подходит нам: да.

2. Cloudflare Pages
   - Цена: бесплатно, кредитка не нужна.
   - Плюс: быстро, хороший хостинг, удобно для будущего домена.
   - Минус: чуть больше настроек, чем Google Sites.
   - Подходит нам: да, лучший технический вариант.

3. Google Sites
   - Цена: можно бесплатно на адресе sites.google.com; домен отдельно.
   - Плюс: очень быстро руками собрать страницу.
   - Минус: хуже выглядит как технический продукт, меньше контроля.
   - Подходит нам: временно, если нужно “сегодня и без кода”.

4. PDF + Google Drive
   - Цена: бесплатно.
   - Плюс: самый быстрый способ отправлять клиентам.
   - Минус: это не витрина, а вложение/презентация.
   - Подходит нам: как запасной материал к письмам.

5. Contra / фриланс-профиль
   - Цена: старт может быть бесплатным, но условия надо проверять перед публикацией.
   - Плюс: ближе к клиентам.
   - Минус: нельзя идти туда без аккуратного описания, демки и честного портфолио.
   - Подходит нам: вторым этапом.

## Решение

Делаем одну страницу Diagnostic Sprint, потом:
- публикуем бесплатно;
- добавляем ссылку в письма;
- собираем 2–3 честных spec/demo примера;
- только после этого идём в витрины и профили.
